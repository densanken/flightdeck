# @flightdeck/rules

Flightdeck の複数の App が同じ規則で判断するための、共通の規則をまとめたパッケージです。
設定ファイルの読み方、Submodule 更新 PR の管理ブランチ名と URL の規則、PR を自動承認・マージしてよいかの判定を提供します。

本パッケージは、渡された入力データのみに基づいて判定結果を返します。GitHub API の呼び出しや実際のレビュー・マージ操作といった副作用は持たず、データの取得と判定結果に応じたアクションの実行は呼び出し元のアプリケーションが担当します。

## モジュール構成

| モジュール | 判定内容                                                                                                  |
| ---------- | --------------------------------------------------------------------------------------------------------- |
| `config`   | 設定ファイルの選択および YAML 構文・スキーマの検証                                                        |
| `naming`   | リポジトリ名や GitHub URL の正規化、Submodule 更新 PR のブランチ名からのソース特定                        |
| `policy`   | PR の種別分類、Gitlink とソース履歴の整合性検証、人間による最終操作の確認、Renovate の automerge 設定評価 |
| `ci`       | Check Run および Commit Status に基づく CI ステータスの集約判定                                           |

公開されている関数および型定義の詳細は [src/index.ts](src/index.ts) を参照してください。

## 設定ファイル（`.github/flightdeck.yml`）

対象リポジトリの `.github/flightdeck.yml`（または `.github/flightdeck.yaml`）について、ファイルの選択と YAML 全体の検証を行います。
各セクションのうち、本パッケージがスキーマを持つのは `autopilot:` セクションです。

> [!NOTE]
> ファイルの取得自体は呼び出し側のアプリケーションで行い、その内容を本パッケージに渡して検証します。設定ファイルが存在しない場合は既定値が返されます。

```yaml
autopilot:
  renovate-stale: false
```

### 設定項目一覧

| 項目                       | 既定値 | 説明                                                      |
| -------------------------- | :----: | --------------------------------------------------------- |
| `autopilot.renovate-stale` | `true` | 一定期間放置された Renovate PR を自動判定の対象に含めるか |

### 設定エラーとなる条件

以下のいずれかに該当する場合、設定エラーとして扱われます。

- `flightdeck.yml` と `flightdeck.yaml` の両方が存在する
- ファイルサイズが 32 KiB を超えている、またはバイナリ等でテキストとして読み取れない
- YAML に構文エラーや警告がある、またはエイリアス（`*` / `&`）が使用されている
- `autopilot` セクション内に未知のキーや不正な型の値が含まれている
